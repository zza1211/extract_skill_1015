## 已修改的执行方式

1. 模型读取按紧凑视图预算分页；同段落/单元格连续文本拼回，只标一次位置。完整 Unicode 偏移与 parts 留在回执。原文、空单位、表格坐标与合并元数据均保留。
2. read/search 的可选参数由 execute 补默认值；全文已读后先保存短候选，再围绕明确疑点搜索。search 检查候选与当前 index 哈希是否匹配，Python 诊断 CLI 保持独立可用。
3. 主 agent 不再 glob/grep 历史产物或未指定输入目录；普通 read 仅用于技能资料和候选。经验按明确索引读取，未提供的附件记录缺失，不猜内容。
4. DeepSeek Flash 项目默认 effort 为 low；显式选过 high/max 的会话可能覆盖默认，因此对照命令显式指定 `--variant low`。
5. 连续表格行、同格多标签、跨页续表不能仅据此成为 separate。校验器对同表相邻/重叠行的 separate 关联给出复核 warning，而不机械把所有同表 separate 判错；对同一采购对象的分散片段数量缺失、但关联条款有数量的情况另给复核 warning，不自动复制数量。
6. 用户对本例的纠错已记录为 E001，带适用与不适用条件；不把一次模型输出冒充人工金标准。
