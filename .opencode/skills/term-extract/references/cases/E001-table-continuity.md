# E001：连续表格行的误分散

版本：1。状态：用户已确认本例的 separate 判断错误；修订后的整篇输出尚未作为人工金标准验收。

来源：HK-M01 校园网络优化标书。错误输出将 Access Points 的 C52–C58 判为 separate，并关联 C44–C48，理由是中间出现控制器 C49–C50。用户明确指出：同一表格的连续两行不算分散条款。

原表上下文：C44–C48 是 AP 标准/覆盖/三频规格；同格 C49–C50 是控制器要求；接着 C52–C55 是每教室并发与每连接带宽，C57–C58 是同时使用 Wi-Fi 的教室数。它们属于连续的 School Wi-Fi Setup & Services 基本规格。

正确处理原则：先保留原表行列和系统上下文，不按 C 标签间隔或单元格拆片判 separate。系统整体性能可以成为关联 AP/AC 的 general，需要章节作用范围取证；不要把控制器参数直接圈入 AP 的硬件区段。若某种输出接口无法表达正确归属，应记录表示限制，不能用错误分类掩盖。

不适用情况：同一采购对象的真正补充技术要求在另一独立章节/非连续业务区段时仍可能是 separate；同一表格内不同型号或 Indoor/Outdoor 独立采购项仍需分别抽取。仅有另一处采购数量清单，不产生 separate。

验证范围：结构测试提示同表相邻/重叠行需要复核；案例的“不是 separate”来自用户确认。模型重新生成、结构检查或本例改善不能替代独立文档的人工回归。
