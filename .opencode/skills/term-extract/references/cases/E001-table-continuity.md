# E001：连续表格行的误分散

版本：2。状态：已确认的处理原则。以下为抽象说明，不包含真实标书、会话记录或模型输出。

适用场景：同一规格表连续描述接入点、控制器和无线系统性能，解析器将它们切成多个标签、单元格或续表。不能仅因中间穿插另一设备的描述，就把连续的系统要求判断为 separate。

判断依据：先看章节、表格行列和约束对象，区分接入点硬件参数、控制器参数，以及并发、带宽等系统性能要求。定位标签的间隔不代表业务区段真正分散。

正确处理原则：先保留原表行列和系统上下文，不按 C 标签间隔或单元格拆片判 separate。系统整体性能可以成为关联 AP/AC 的 general，需要章节作用范围取证；不要把控制器参数直接圈入 AP 的硬件区段。若某种输出接口无法表达正确归属，应记录表示限制，不能用错误分类掩盖。

不适用情况：同一采购对象的真正补充技术要求在另一独立章节/非连续业务区段时仍可能是 separate；同一表格内不同型号或 Indoor/Outdoor 独立采购项仍需分别抽取。仅有另一处采购数量清单，不产生 separate。

验证要求：结构测试只提示同表相邻/重叠行需要复核，不能直接决定条款归属。应在独立文档上检查误分散、参数污染和关键参数遗漏。
